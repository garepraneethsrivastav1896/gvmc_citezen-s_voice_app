# CivicPulse 🏙️⚡
*AI-Powered Smart City Governance & Complaint Management Platform*

---

## 📌 Overview
**CivicPulse** is an advanced, AI-driven civic engagement and municipal complaint management platform. Designed to bridge the gap between citizens and city authorities, it streamlines the process of reporting, tracking, and resolving urban infrastructure and community issues. Leveraging cutting-edge AI and mapping services, CivicPulse automates complaint triaging, optimizes resource allocation, and fosters transparent urban governance.

---

## 🚀 Key Features

*   **🤖 AI-Powered Complaint Analysis:** Integrates the **Google Gemini API** to automatically analyze user-uploaded images and descriptions, instantly determining issue categories, suggesting titles, and assessing severity levels.
*   **📍 Precise Geolocation & Mapping:** Utilizes the **Google Maps API** for accurate coordinate tagging, enabling interactive map views and heatmap generation of complaint "hotspots" for administrators.
*   **👥 Role-Based Access Control (RBAC):**
    *   **Citizens:** Report issues, track live status updates, and earn community rewards.
    *   **Field Workers:** View assigned tasks, update work progress, and upload resolution proof.
    *   **Administrators:** Centralized dashboard for user management, workload assignment, and real-time analytics.
*   **🏆 Gamification & Rewards:** Encourages civic participation through points, digital badges, leaderboards, certificates, and community partner coupons.
*   **🔒 Secure Authentication:** Implements robust security features including JSON Web Tokens (JWT) and OTP-based verification.

---

## 🛠️ Tech Stack

*   **Frontend:** Angular / React, Tailwind CSS
*   **Backend:** Node.js, Express.js
*   **Database & Storage:** Firebase / MongoDB
*   **AI & APIs:** Google Gemini API, Google Maps Platform
*   **Deployment:** Google Cloud Run
